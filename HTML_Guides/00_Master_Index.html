👤 12 YOE Senior Strategy Notes

✅ What to emphasize

  • ✔ Connect DSA answers to real DS/ML/GenAI systems
  • ✔ Explain time/space tradeoffs — not just give solution
  • ✔ Mention production concerns: memory, concurrency
  • ✔ Optimize first, then code — show senior thinking
  • ✔ Trees → Decision Trees; Graphs → GNN, RecSys; DP → Optimization
  • ✔ LRU Cache → caching layers in ML serving
  • ✔ Sliding Window → stream processing in data pipelines

❌ Common mistakes to avoid

  • ✗ Don't start coding before understanding the problem
  • ✗ Don't skip edge cases: empty input, null, single element
  • ✗ Don't confuse sorted vs unsorted input assumptions
  • ✗ Don't use O(n²) when O(n) is achievable with HashMap
  • ✗ Don't forget to handle negative numbers in sum problems
  • ✗ Don't use global variables — use parameters + return
  • ✗ Don't panic on Hard questions — start with brute force
