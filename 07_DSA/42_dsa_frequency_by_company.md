## COMPARISON TABLE

| Aspect | Product Companies | Captive Centers |
|--------|-------------------|-----------------|
| **Difficulty** | Easy to Hard | Easy to Medium |
| **Focus** | Optimization, edge cases | Fundamentals, correctness |
| **Time limit** | 45–60 min | 30–45 min |
| **Expected approach** | Optimal solution | Working solution |
| **Most asked topics** | DP, Graphs, Trees | Arrays, Strings, LinkedLists |
| **Least asked topics** | Basic math, simple arrays | Advanced DP, complex graphs |
| **Interview style** | Follow-ups, optimization | Straightforward questions |
| **Coding style** | Clean, optimized code | Working code is enough |

## STUDY STRATEGY BY COMPANY TYPE

### For Product Companies
1. **Master Q1–50** (Foundations) — 1 week
2. **Master Q51–120** (Intermediate) — 2 weeks
3. **Master Q121–180** (Advanced) — 2 weeks
4. **Focus on:** DP, Graphs, Trees, Optimization
5. **Practice:** 3–5 hard problems per day
6. **Mock interviews:** 2–3 per week

### For Captive Centers
1. **Master Q1–50** (Foundations) — 1 week
2. **Master Q51–90** (Intermediate Part 1) — 1 week
3. **Focus on:** Arrays, Strings, LinkedLists, Stacks, Queues
4. **Practice:** 5–10 easy problems per day
5. **Mock interviews:** 1–2 per week
6. **Skip:** Q121–180 (unless applying for senior roles)

## QUICK REFERENCE: What to Study

### If you have 1 week
- Master Q1–30 (Arrays + Strings)
- Practice daily on LeetCode Easy
- Focus on correctness, not optimization

### If you have 2 weeks
- Master Q1–50 (Foundations)
- Practice Q1–50 twice
- Add Q51–70 (Sorting + Searching)

### If you have 3 weeks
- Master Q1–90 (Foundations + Intermediate Part 1)
- Practice each problem 2–3 times
- Add Q91–110 (LinkedLists + Two Pointers)

### If you have 4–6 weeks
- Master Q1–180 (All phases)
- Practice each problem 2–3 times
- Do 2–3 mock interviews per week
- Review weak areas

### If you have 8+ weeks
- Master Q1–180 multiple times
- Solve additional problems on LeetCode
- Do mock interviews 3–4 times per week
- Study system design basics

## FINAL TIPS

### For Product Companies
- ✅ Optimize for time and space
- ✅ Explain your approach clearly
- ✅ Handle all edge cases
- ✅ Ask clarifying questions
- ❌ Don't just brute force
- ❌ Don't skip optimization

### For Captive Centers
- ✅ Write clean, working code
- ✅ Test with examples
- ✅ Explain step by step
- ✅ Handle basic edge cases
- ❌ Don't over-optimize
- ❌ Don't skip fundamentals
